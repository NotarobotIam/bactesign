# Reference collection provenance

This is a bounded reference collection, not a complete copy of any source and not an antimicrobial efficacy ranking.

- ChEMBL: 120 named records with chemical structures selected from the first API page returned by `https://www.ebi.ac.uk/chembl/api/data/molecule.json?max_phase=4&limit=120`. Attribution: ChEMBL, EMBL-EBI. Data license: Creative Commons Attribution-ShareAlike 3.0 Unported, https://creativecommons.org/licenses/by-sa/3.0/. Names were title-cased and selected metadata extracted. The ChEMBL-derived portion of this collection is distributed under that license. Source record URLs are retained individually.
- PubChem: 130 CID/property records obtained using the full InChIKeys in that ChEMBL selection. Requested properties: Title, MolecularFormula, MolecularWeight, InChIKey. Returned identities were accepted only when the full InChIKey agreed. Several CIDs can share a full InChIKey. Attribution: PubChem, NCBI/NLM. Full provenance and original source URLs are retained. PubChem data usage guidance: https://pubchem.ncbi.nlm.nih.gov/docs/data-usage-policies.
- DRAMP: 120 complete records with names/IDs and uppercase peptide sequences, selected in source order from the General dataset TXT download linked at https://dramp.cpu-bioinfor.org/downloads/. Attribution: DRAMP, Zheng group. Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/. Selected annotations, modifications, source references and sequences were extracted. The DRAMP-derived portion is distributed under CC BY 4.0. Names and original field text were preserved; no sequence-based identity merging was performed.

Per-record retrieval timestamps and original URLs are in molecule-catalog.json. These license statements apply to the respective source data, not to the application code or to user-generated measurements. No literature MIC values were loaded as experimental Bactesign results. No clinical status or efficacy is inferred from collection inclusion.

## Expanded collection

The larger separately distributed reference snapshot contains 994 named, structured ChEMBL records from the first 1,000 max_phase=4 API records; 1,158 matching PubChem CID/property source records; and 11,972 DRAMP General entries with IDs and supported uppercase-letter sequences. The same source attribution, data licenses and transformation descriptions above apply. ChEMBL names were title-cased. DRAMP names were capped at 250 characters for the application; original source links are retained. 812 DRAMP source entries with missing or unsupported sequence representations were skipped without inferring structures. This is not a claim that those source entries are biologically invalid. Peptide records are not merged by sequence alone. The source export is separate from the app bundle to avoid shipping large datasets in every request.
